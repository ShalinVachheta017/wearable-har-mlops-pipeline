📝 Window Predictions

#ActivityIDConfidence
How it works: Your CSV is split into sliding windows of 200 samples (50% overlap). Each window is classified by a 1D-CNN-BiLSTM model. Then 3-layer monitoring checks confidence, temporal consistency, and distribution drift. High temporal transition rate can mean noisy predictions or genuinely frequent movement changes. Labeled uploads are marked as retraining-eligible, but model mutation remains gated outside this API call.
