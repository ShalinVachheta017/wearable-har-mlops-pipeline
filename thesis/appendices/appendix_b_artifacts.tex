\chapter{Runtime Contract and Artifact Inventory}
\label{app:artifacts}

This appendix documents the deployable proposed-model package. The deployment unit is not the model file alone but the complete runtime contract: the model, its train-only scaler, the fixed label order, the monitoring baseline, the contract metadata, and the integrity record must be promoted together, as argued in Chapters~\ref{chap:architecture}--\ref{chap:implementation}. All artifacts below reside in the same runtime-contract folder, \path{models/runtime_contract/model_d1_final_20260528/}.

The model expects input of shape \((200,6)\) at 50~Hz, a 200-sample window with a 100-sample stride, accelerometer channels in m/s\textsuperscript{2} and gyroscope channels in deg/s, and the eleven-class label order above. Deployment or probe data are never used to fit the scaler; the saved Garmin train-only scaler is reused to preserve train--serve parity.
