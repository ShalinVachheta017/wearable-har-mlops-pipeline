\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This thesis develops an offline-first MLOps pipeline for wearable-sensor-based behavioral-proxy recognition in a mental-health-adjacent monitoring context. The work focuses on wrist-worn inertial measurement unit data and treats anxiety-related repetitive activities as observable activity classes rather than as clinical mental-health labels. The technical contribution is therefore not a diagnostic or prognosis model, but a reproducible and governed machine-learning lifecycle for wearable Human Activity Recognition.

The pipeline connects ingestion, validation, preprocessing, inference, evaluation, monitoring, trigger evaluation, and governed retraining boundaries into one auditable workflow. A central design principle is the runtime contract: the model, sensor schema, unit convention, scaler, label order, monitoring baseline, and evaluation evidence are treated as one deployment unit. This prevents silent train--serve mismatch, such as using a model with an incompatible scaler, channel order, or baseline.

The final runtime candidate uses a 1D-CNN-BiLSTM model for eleven-class wrist-motion activity recognition from 50~Hz IMU windows of shape \((200,6)\). The system is evaluated under labeled development data, held-out-user conditions, a blind self-recorded User~7 probe, and deployment-style unlabeled inference. The thesis shows that reliable wearable monitoring requires more than model accuracy: it requires explicit preprocessing assumptions, run-scoped evidence, monitoring signals, and governance rules that separate operational risk detection from automatic model mutation.

\bigskip
\noindent
\textbf{Keywords:} wearable HAR, MLOps, offline-first pipeline, distribution shift, retraining governance, train--serve consistency, trigger policy

\chapter*{Zusammenfassung}
\addcontentsline{toc}{chapter}{Zusammenfassung}

Diese Masterarbeit entwickelt eine offline-first MLOps-Pipeline für die Erkennung von beobachtbaren Verhaltensmustern mit tragbaren Sensordaten. Der Anwendungskontext ist mentales Gesundheitsmonitoring. Die Arbeit macht jedoch keine klinische Diagnose und keine Prognose. Stattdessen werden wiederholte Hand- und Handgelenkbewegungen, zum Beispiel Nagelkauen, Haarezupfen, Kratzen, Tippen oder Reiben, als Aktivitätsklassen behandelt.

Die Pipeline verarbeitet Sensordaten einer Smartwatch mit Beschleunigungs- und Gyroskopsignalen. Sie umfasst Datenaufnahme, Validierung, Vorverarbeitung, Inferenz, Evaluation, Monitoring, Trigger-Entscheidung und kontrollierte Grenzen für erneutes Training. Ein wichtiger Beitrag ist der sogenannte Runtime Contract. Dabei werden Modell, Sensor-Schema, Einheiten, Skalierer, Label-Reihenfolge, Monitoring-Basislinie und Evidenz gemeinsam betrachtet. Dadurch sollen stille Fehler zwischen Training und Anwendung vermieden werden.

Das finale Laufzeitmodell ist ein 1D-CNN-BiLSTM-Modell für elf Aktivitätsklassen. Es nutzt IMU-Fenster mit der Form \((200,6)\) bei einer Abtastrate von 50~Hz. Die Arbeit zeigt, dass ein tragbares Monitoring-System nicht nur ein trainiertes Modell braucht. Es braucht auch klare Vorverarbeitung, reproduzierbare Artefakte, Monitoring-Signale und Governance-Regeln, damit Warnungen nicht automatisch zu unsicherem Modelltraining führen.
