# Workflow Paper Mapping Hub

This tracked folder contains chapter-wise paper bifurcation manifests for thesis writing.

## Why This Folder Exists

`internal/papers/` is ignored by git in this repository, so writing-control manifests are maintained here under `internal/workflow/literature/`.

## Files

- `chapter_buckets.md`: chapter-to-paper assignment map for `ch1` to `ch8`.
- `archive_candidates.md`: duplicate/archive-candidate policy for triage papers.

## Source Binary Folders

These manifests map papers stored under:

- `internal/papers/core/`
- `internal/papers/sorted/`
- `internal/papers/triage/`

## Usage

1. Open `chapter_buckets.md` while drafting each thesis chapter.
2. Prioritize `core-anchor` papers first, then add `candidate` papers as needed.
3. Use `archive_candidates.md` to avoid citing duplicate/low-quality variants.
4. Sync updates to thesis chapter notes when section framing changes.
