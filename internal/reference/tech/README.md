This folder is the canonical, defense-friendly technology reference set for the thesis.

- `dvc.md`
- `mlflow.md`
- `fastapi.md`

## Scope rule

Each file answers the same four questions:

1. What is this technology (general concept)?
2. Why is it used in this thesis repository?
3. Which repository files/folders implement it?
4. Is it core, optional, or future work in this project?

## Note on older files

Earlier explainers still exist in `internal/reference/` (for example `docker_explained.md`, `dvc_explained.md`, `mlflow_explained.md`).

For thesis writing and defense consistency, prefer this `internal/reference/tech/` set as the source of truth.
